# Custom Map Maker

지도 기반 제보/장소 서비스를 빠르게 만들기 위한 CMS MVP입니다.

## 요약

- 목표: 공개 지도 화면과 운영자 승인 화면을 빠르게 구축한다.
- 현재 스택: `Next.js 16` + `TypeScript` + `MapLibre GL JS`
- 현재 범위: 장소 목록, 카테고리, 공개/승인대기 상태, 공개 지도, 관리자 대시보드
- 제품 방향: 범용 CMS보다 "제보형/장소형 지도를 빠르게 운영하는 도구"에 집중한다.

## 현재 구현 상태

### 공개 지도

- 한국 중심 좌표 사용
- 장소 목록과 지도 동시 표시
- 카테고리 표시
- 마커 클릭 시 팝업 표시
- 관리자 화면으로 이동 가능

### 관리자 화면

- 총 장소 수
- 승인 대기 수
- 카테고리 수
- 검수 목록 표시

## 왜 이렇게 시작했는가

- 처음부터 범용 CMS로 넓히면 범위가 과도해진다.
- MVP는 지도 기반 제보/장소 관리 흐름이 실제로 유효한지 검증하는 데 집중해야 한다.
- 그래서 현재는 데이터 공개와 검수 흐름의 시작점만 구현했다.

## 로컬 실행

```bash
yarn install
yarn dev
```

- 공개 화면: `http://localhost:3000`
- 관리자 화면: `http://localhost:3000/admin`

## 한국 지도 반영 원칙

- 기본값은 한국 중심 좌표와 한국 범위에 맞춘다.
- API 키 없이도 검증 가능하도록 기본 타일은 공개 타일을 사용한다.
- 이후 국내 지도 공급자는 환경 변수 기반으로 교체할 수 있게 확장한다.
